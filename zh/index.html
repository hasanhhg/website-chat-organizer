常见问题

常见问题解答

这是免费的吗？
是的，完全免费。没有订阅、没有高级套餐、没有隐藏费用，永远如此。
我需要 API 密钥吗？
不需要。AI 分类在共享后端上运行，对你完全免费。只需安装扩展程序并点击整理即可。
它会删除我的对话或项目吗？
不会删除任何对话。整理后完全为空的项目会被删除以保持侧边栏整洁，但每个对话都完整保留在你的聊天历史中。
它支持英语以外的其他语言吗？
是的。关键词词汇表涵盖荷兰语、法语、德语、西班牙语、意大利语、波兰语、俄语、阿拉伯语、印地语等更多语言。AI 备选方案支持任何语言。
我需要登录 Claude.ai 吗？
是的。扩展程序使用你活动的 Claude.ai 浏览器会话来读取和移动对话。打开 claude.ai，登录，然后点击扩展程序图标。
我可以撤销整理操作吗？
不能自动撤销，但你可以在 Claude.ai 中手动移回对话。这就是为什么预览步骤存在：在点击应用之前仔细检查计划。
How do I organize my Claude chats?
Install the Chat Organizer extension, open Claude.ai, and click Organize. It scans every unorganized chat, picks a project for each one using keyword matching and AI, and moves them all in one click once you approve the plan. No manual sorting, no API key.
Is there a tool to manage and organize hundreds of Claude conversations?
Yes. Chat Organizer is a free Chrome extension made to manage and organize large Claude.ai chat histories. It sorts hundreds of conversations into projects automatically, so you can find an old chat in seconds instead of scrolling forever.
Does it work with ChatGPT?
Yes. Chat Organizer works on both Claude and ChatGPT. Pick the platform in the popup (it auto-detects the tab you are on) and organize either sidebar the same way, with the same one-click preview. See the ChatGPT guide for details.
What is the best AI chat organizer?
The best AI chat organizer is the one that sorts your existing backlog for you rather than making you file chats by hand. Chat Organizer is a free AI chat organizer for Claude and ChatGPT: it reads your unorganized conversations, works out what each one is about using keyword matching plus AI, and moves them all into projects in one click. You approve a full preview first, and nothing is ever deleted.
Is there a ChatGPT chat organizer Chrome extension?
Yes. Chat Organizer is a free Chrome extension that organizes ChatGPT chats into Projects automatically. Open chatgpt.com, click Organize, review the plan, then click Apply. It needs no API key and no account, and it organizes Claude chats too. See the ChatGPT guide.
